# Rust Essential Training 🦀

This repository tracks my journey into systems programming, containing practice code, chapter exercises, and project notes from the **[Rust Essential Training](https://www.linkedin.com/learning/rust-essential-training)** course on LinkedIn Learning, instructed by Barron Stone.

The primary goal of this repository is to build a rock-solid foundation in Rust's unique ecosystem, focusing on memory safety, zero-cost abstractions, and robust application design.

---

## 📚 Core Topics Covered

### 1. Language Fundamentals
* **Syntax & Control Flow:** Mastering variables, mutability, scalar/compound data types, loops, and conditional logic.
* **Tooling with Cargo:** Managing dependencies, compiling efficiently, and organizing projects.

### 2. The Rust Memory Model
* **Ownership & Borrowing:** Understanding how Rust manages memory without a garbage collector.
* **References & Lifetimes:** Preventing data races and ensuring reference validity at compile time.

### 3. Data Structures & Architecture
* **Types & Polymorphism:** Grouping data with `structs` and defining behavior with `traits`.
* **Pattern Matching:** Utilizing `enums` and the `match` control flow operator for type-safe state handling.
* **Code Organization:** Splitting applications logically using modules and crates.

### 4. Reliability & Diagnostics
* **Error Handling:** Managing recoverable errors via `Result` and unrecoverable errors via `panic!`.
* **Testing:** Writing unit and integration tests to ensure code correctness.

## 🚀 Getting Started

To run any of the projects or exercises locally, ensure you have the [Rust toolchain installed](https://rust-lang.org), then clone this repository and use `Cargo`:

```bash
# Clone the repository
git clone https://github.com

# Navigate to a specific exercise or project folder
cd folder-name

# Build and run the project
cargo run
```
